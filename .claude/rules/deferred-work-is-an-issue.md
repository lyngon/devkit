# Deferred work is an issue

Work that the owner defers in this repository becomes a GitHub issue that states a goal, a done check, what is known and, under "Not before", what it waits for and the date of the deferral, and that never carries the label `ready`.
No file in the tree holds deferred work, also where a skill says to write `docs/TODO.md`, as `discover:brainstorm` does.

Why: the plugins tell an agent in every repository to write deferred work to `docs/TODO.md`, so an agent that follows them here brings the file back with nothing failing.
