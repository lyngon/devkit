# lyngon-repo

Repository setup for Lyngon.

## Skills

- `/lyngon-repo:init`: interview the owner about purpose, audiences, stack and constraints, then create or adopt the standard repository files.
  Works on empty repositories and on existing ones.
  User-invoked only.

## Install

```sh
claude plugin marketplace add lyngon/skills
claude plugin install lyngon-repo@lyngon
```
