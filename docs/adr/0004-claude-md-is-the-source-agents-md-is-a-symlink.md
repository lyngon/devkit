# `CLAUDE.md` is the source file; `AGENTS.md` is a symlink to it

Most ecosystems treat `AGENTS.md` as the canonical agent context and symlink `CLAUDE.md` to it.
This repository is primarily for Claude Code, with other agents a possible future scope, so the file people edit is `CLAUDE.md` and `AGENTS.md` is the symlink.
Both names resolve to the same content, so the only thing this decides is which name appears in editors, diffs and instructions.
If a second agent becomes a first-class consumer, reverse the link direction; the content does not change.
